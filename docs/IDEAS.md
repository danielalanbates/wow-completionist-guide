# Future ideas (2026-11-10)

Three independent finders proposed 60 ideas. One looked at routing gaps, one at routing internals, and one at what players use in free addons. A fourth pass merged the duplicates. It then checked every remaining idea against the repo at commit `92aa479` by reading and grepping the code. No harness, sweep, vplayer run or build was started, because a long optimizer job had the 8 GB Mac busy. Ideas that were already done were dropped, ideas that were partly done say "extends", and five "critic" ideas were added for angles nobody covered.

Hard rules for anyone picking these up:

- **Data sources.** Quest and NPC data come only from the Warcraft Wiki (warcraft.wiki.gg, CC BY-SA 4.0) and Blizzard client data (wago.tools DB2).
- **Independence.** The project stays fully independent of commercial guide products. Never name one, and never read, import or imitate their content.
- **Testing.** Daniel beta-tests in game himself. AI never logs into Battle.net or drives the game. Verification is offline (`tools/vplayer.lua`, `route_sweep`, `test_*.lua`) plus his reports.
- **Licence.** The addon is free for players. Code is PolyForm Noncommercial with the 10% rider, and wiki-derived data ships under CC BY-SA.
- **8 GB Mac.** Never start a heavy job while another one is running.

Effort: S = one session, M = a few sessions, L = a full workstream, XL = several workstreams. Value: 1 (nice to have) to 5 (players notice at once, or it blocks v2.0). Nothing here has run in a real client.
